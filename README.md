# Mini SOC

Mini SOC / SIEM·SOAR 기반 로그 수집·침해 탐지·상관분석·대응 자동화 플랫폼

## Goal

Nginx Access Log와 Linux Authentication Log를 수집하고,
공통 Security Event 형식으로 정규화한 뒤 탐지, 상관분석,
Risk Score, Alert, Incident, Response까지 연결하는 것을 목표로 한다.

Initial project setup in progress.
